# 沈志华冷战史论文集 | Shen Zhihua Cold War Papers

> 本仓库系统整理沈志华教授冷战国际史研究论著目录，涵盖中文专著、论文及英文翻译/合作著作，并收录冷战史核心档案、机构、学者、期刊等参考资料体系。

**沈志华**，华东师范大学历史系终身教授，冷战国际史研究中心主任，周边国家研究院院长。1950年生，研究领域为冷战国际史、苏联史、中苏关系、中朝关系。出版专著12部，主编档案集60余卷，发表中英俄日韩等多语种学术论文100余篇。
